# 今日家でご飯食べる? 🏠🍴

家族やグループで「今日、家で夜ご飯を食べるか」を共有するためのWebアプリケーションです。

## 特徴

- 📅 **月間カレンダービュー**: 1ヶ月先までの予定を一目で確認
- 👤 **ユーザー管理**: LocalStorageを使用して名前を保持
- 🏠 **回答の切り替え**: 「家で食べる」「外で食べる」「未定」を簡単に切り替え
- 👥 **グループ表示**: 各日付に誰が回答したか一目でわかる
- 🌙 **ダークモード**: 夜間でも見やすい落ち着いたデザイン
- 📱 **モバイルフレンドリー**: スマートフォンでも快適に使用可能

## 技術スタック

- **React**: UIライブラリ
- **Vite**: ビルドツール
- **Tailwind CSS**: スタイリング
- **Lucide React**: アイコン
- **LocalStorage**: データ永続化

## デプロイ（最も簡単）

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/jjjolly/eatathome)

上のボタンをクリックするだけで、Vercelに自動デプロイされます。

### 手動でデプロイする場合

1. [Vercel](https://vercel.com) にアクセス
2. GitHubアカウントでログイン
3. 「New Project」をクリック
4. このリポジトリ（jjjolly/eatathome）を選択
5. 「Deploy」をクリック

## ローカル環境でのセットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番ビルド
npm run build
```

## 使い方

1. **初回起動**: 名前を入力して「利用開始」をクリック
2. **カレンダー操作**: 日付をタップして回答を切り替え（🏠 → 🍴 → ❓）
3. **メンバー追加**: ヘッダーの「+」ボタンからメンバーを追加
4. **設定**: 歯車アイコンからユーザー情報の確認やログアウトが可能

## データの保存

全てのデータはブラウザのLocalStorageに保存されます。そのため：

- サーバーへの接続は不要
- データはブラウザごと、デバイスごとに独立
- ブラウザのデータをクリアすると全て削除される
